# 차량 등록 패널 개선

기준: 2026-10-15

## 기획 판단

차량 등록은 목록 조회 중 잠시 수행하는 보조 작업이다. 목록 위에 긴 폼을 삽입하면 기존 카드 위치가 바뀌므로, 목록을 유지하는 오른쪽 드로어를 선택했다. 작은 화면에서는 가로 공간이 부족해 하단 시트로 전환한다. 모션은 작업 공간이 열리고 닫히는 방향을 전달하는 데만 사용한다.

## 적용

- 열기 260ms, 닫기 220ms. 배경 페이드와 패널 슬라이드.
- 600px 이하 하단 시트, 최대 94dvh, 내부 스크롤 및 고정된 닫기 영역.
- native dialog, 첫 입력 포커스, Tab/Shift+Tab 순환, Esc 닫기, 배경 스크롤 잠금과 복구.
- 작성 내용은 닫아도 유지하며 새로고침·로그아웃 시 초기화됨을 안내. 저장 중 닫기 방지.
- 등록 성공 시 기존 저장 흐름으로 초기화·목록 갱신·닫기. 저장 API와 DB 정책은 변경하지 않음.

## 검증 결과와 범위

- lint·프로덕션 빌드 성공, 기존 자동 테스트 26개 통과. Docker 프런트엔드 재배포 완료.
- 실제 데스크톱에서 열기/닫기, Esc, 입력 유지, 버튼 진입 시 포커스 복귀, 키보드 순환 확인.
- 기존 `#vehicle-form` 직접 진입 시 패널과 첫 입력 포커스 확인. 닫으면 `#vehicles` 복귀.
- 390×844 모바일에서 하단 배치, 내부 스크롤, 하단 입력·등록 버튼 접근 및 가로 넘침 없음 확인.
- 현재 브라우저는 `prefers-reduced-motion: reduce`를 반환하여 애니메이션 생략을 실제 확인했다. 일반 모션의 방향·시간은 CSS와 빌드로 확인했으며, 시스템 설정을 바꾸어 재생하는 검증은 하지 않았다.
- 등록 성공/저장 중 닫기 방지는 기존 저장 흐름과 코드 연결을 검토했다. 이번 UI 검증에서 추가 차량을 저장하거나 기존 데이터를 변경하지 않았다.
- 최종 브라우저 오류 로그 없음.
