# 화면 개선 디자인·개발 인계서

기준: 2026-10-15 · 기획서 [PRODUCT_REVIEW.md](PRODUCT_REVIEW.md) UX-01~18

## 역할별 결정

기획: 사용자가 정비 필요 항목을 먼저 발견하고 이유와 다음 행동을 이해하게 한다.
디자인: 상단의 반복 요약을 줄이고 조회 도구 → 상태 카드 → 실행 버튼 순으로 읽히게 한다.
개발: 계산·필터는 순수 함수로 분리하고 기존 API·권한·버전 검증을 재사용한다.

## 화면 구조

1. 헤더: 서비스 홈, 브라우저 알림 이동, 로그아웃. 본문 바로가기 제공.
2. 제목: 차량/소모품 수, 마지막 갱신 시각과 새로고침.
3. 네 탭: 정비 현황 / 차량 관리 / 소모품 등록 / 알림. 상단 고정, 키보드 이동 유지.
4. 정비 현황: 차량 선택+제품/종류 검색 → 상태 필터 → 결과 수+기본 정렬 안내 → 카드.
5. 카드: 차량명 → 소모품 이름/상태 → 거리 또는 기간 주 지표 → 날짜 근거/최근 교체 → 교체 기록/이력 → 링크/삭제.
6. 차량 관리: 카드별 주행거리 갱신과 소모품 등록. 차량 등록은 데스크톱 오른쪽 패널, 모바일 하단 시트로 열림.
7. 등록: 필수 기록을 먼저, 구매 링크는 선택 상세로 접어서 제공. 거리/기간 주기는 빈 값으로 시작.
8. 알림: 브라우저 권한 및 동작 범위 안내 → 전체/미확인 → 관련 현재 상태로 이동.

## 시각 규칙

- 브랜드 파랑 유지. 본문 #0f172a, 보조 문구 #475569/#64748b, 배경 #f8fafc, 카드 흰색.
- 상태는 빨강(교체 필요), 주황(임박), 초록(정상)과 텍스트를 함께 사용.
- 기본 본문 14px 이상, 보조 문구 12px 이상을 목표로 조정. 장식용 작은 배지는 예외.
- 주요 조작 최소 높이 44px. 카드의 보조/위험 행동은 시각적 강조를 낮추되 조작 영역은 확보.
- 카드 상단 여백과 반복 구매 안내를 줄인다. 긴 제품명·차량명·URL은 카드 밖으로 넘치지 않음.
- 데스크톱 카드 3열, 중간 너비 2열, 작은 화면 1열. 필터는 모바일에서 세로 배치.
- 전역 scrollbar-gutter와 고정 탭을 유지. 폼 입력 포커스가 고정 메뉴 아래에 가려지지 않게 여백 확보.

## 정보·상호작용 계약

| 항목 | 계약 |
| --- | --- |
| 정렬 | 상태 우선순위 고정, 같은 상태는 남은 거리/날짜와 ID로 안정적인 순서. 목록 원본을 변형하지 않음 |
| 상태 수 | 선택 차량 기준 개수. 검색 결과 수는 별도 표시해 모수가 혼동되지 않게 함 |
| 검색 | 제품명·소모품 종류·차량명, 공백 제거 후 대소문자 무시. 검색 결과 없음은 필터 초기화 제공 |
| 주 지표 | 기간 만료면 날짜 우선, 그 외 거리 주기 있으면 거리, 기간 전용이면 일수 |
| 날짜 | 두 날짜 중 빠른 것을 표시하되 출처를 명시. 거리 추정일이 없으면 허위 날짜를 생성하지 않음 |
| 차량 사전 선택 | 차량 카드의 등록 버튼은 그 차량을 전달. 다른 차량의 미저장 작성이 있으면 확인 후 전환 |
| 필드 오류 | 화면에 입력값 유지, 필드 아래 오류 표시, 첫 오류로 포커스. 저장 실패에 성공 안내를 표시하지 않음 |
| 알림 | 미확인 필터는 readAt 기준. 링크는 관련 소모품을 좁혀 보여줌. 브라우저 권한을 자동 요청하지 않음 |
| 링크 | 저장된 판매처만 새 창으로 열기. 제휴/추천으로 표시하지 않음 |
| 삭제 | 기존 소프트 삭제와 확인창 유지. 목록 제외·알림 중단·화면 복구 불가를 설명 |

## 검수 기준

### 차량 등록 패널 (2026-10-15 추가)

- 목적: 목록의 위치를 바꾸지 않고, 잠시 집중해야 하는 등록 작업을 별도 공간으로 구분한다.
- 데스크톱은 오른쪽에서, 600px 이하에서는 아래에서 진입한다. 열기 260ms / 닫기 220ms, 배경은 함께 페이드한다.
- 모션 줄이기 설정에서는 애니메이션을 생략한다. 반복·튕김·장식용 모션은 넣지 않는다.
- native dialog로 배경 조작을 차단하고 키보드 포커스를 패널 안에 유지한다. 첫 입력란에 포커스하고 닫으면 진입 위치로 돌려준다.
- 닫기 버튼과 Esc를 제공한다. 저장 중에는 닫기를 막고, 폼이 길어지면 패널 내부만 스크롤한다.
- 닫아도 작성 내용을 유지한다. 새로고침·로그아웃은 초기화되며 이 범위를 화면에 안내한다. 등록 성공 시 초기화·닫기·목록 갱신한다.
- 기존 `#vehicle-form` 직접 주소도 패널을 열며, 닫으면 `#vehicles`로 돌아간다.

### 공통 검수

- 기본 데이터에서 초과 항목이 첫 카드. 상태/차량/검색을 함께 적용해도 올바른 교집합.
- 기간 전용 카드에 거리 없음이 주 지표로 나오지 않음. 만료된 기간과 남은 거리를 혼동하지 않음.
- 검색 결과 없음 → 초기화, 차량 없음 → 차량 등록, 소모품 없음 → 소모품 등록의 경로가 작동.
- 탭 이동 후 작성 유지, 직접 URL/뒤로 가기, 키보드, 모바일 가로 넘침과 모달 취소 확인.
- 실제 API 실패와 충돌은 기존 안내와 추적 코드 유지. 기존 테스트 회귀 확인.
- 교체 기록/삭제/권한 정책을 화면 개편 때문에 바꾸지 않음.
