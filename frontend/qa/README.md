# Docker 없이 UI 검수

프런트엔드 폴더에서 `pnpm qa` 실행 후 다음 주소를 연다.

- 기본: http://127.0.0.1:3001/qa/#vehicles
- 차량 없음: http://127.0.0.1:3001/qa/?scenario=empty#maintenance-status
- 접힌 구매 링크의 필드 오류: http://127.0.0.1:3001/qa/?scenario=field-error#maintenance-form

기본 화면은 차량 2대, 첫 차량의 소모품 3개(교체 필요/임박/정상 각 1개)를 사용한다.
백엔드 프록시가 없고 모든 변경 요청은 명시적으로 거절한다. 저장 성공이나 DB 정합성을 검증하는 환경이 아니다.
변경 요청은 500ms 뒤 실패하므로 로딩·중복 조작 차단·오류 후 입력 유지·필드 포커스를 검수할 수 있다.

실제 배포는 기존 `pnpm build` / Docker Compose로 수행한다. `/qa/index.html`은 기본 프로덕션 빌드의 진입점이 아니며,
검수 미들웨어도 프로덕션 번들에 포함하지 않는다. 포트는 127.0.0.1:3001에만 바인딩한다.

이 환경의 스크린샷은 반드시 **가상 데이터 검수**로 표시한다. 실제 API 저장·세션·DB 검증과 혼동하지 않는다.
